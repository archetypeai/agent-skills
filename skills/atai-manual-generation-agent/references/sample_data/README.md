# Sample data

Reference **outputs**, not inputs. Three MGA runs over the same video, differing
only in configuration, plus the reference step annotations to score them against.

| File | What it is |
|---|---|
| `mga-output-truncated-active-blueprint.jsonl` | The **active** `mga` blueprint, `max_frames: 64`. 6 steps, 16–85 s, last step cut mid-clause. What ships today. |
| `mga-output-max_new_tokens2048.jsonl` | Same video and instruction, `max_new_tokens: 2048`. 10 steps, 16–120 s, clean. |
| `mga-output-max_new_tokens2048-coverage-prompt.jsonl` | Also a coverage-oriented `prompt`. 19 steps, 11–139 s, clean. |
| `40567_i2JWkDyg26A_reference_steps.csv` | Reference annotations: `<step>,<start_sec>,<end_sec>`, two independent annotators. |

Score any of them offline, no API key needed:

```sh
python3 ../run_mga_agent.py --score mga-output-max_new_tokens2048.jsonl \
    --reference 40567_i2JWkDyg26A_reference_steps.csv
```

## Why no video ships here

The source is a **YouTube video, copyrighted by its uploader**. CrossTask itself
distributes annotations and video IDs only, never the media, and this skill does the
same. `run_mga_agent.py --video <path>` takes your own file; the worked example repo
fetches the sample with `yt-dlp` at run time.

## The video these outputs came from

[`i2JWkDyg26A`](https://www.youtube.com/watch?v=i2JWkDyg26A) — "How to change a wheel
on your Toyota", 173.2 s, 640×360, 25 fps, 4,329 frames. Chosen because it sits at
58% of MGA's ~5-minute ceiling and has all 11 reference steps annotated.

## A caveat on the reference steps

CrossTask's 11 steps are declared **per task**, derived from a wikiHow article — a
reference *procedure*, not an inventory of the video. Actions the article omits
("remove the hubcap", "switch off the ignition") cannot appear in it, so an MGA step
with no reference match is not necessarily wrong. Score recall against it; do not
score precision.

The two annotators also disagree, sometimes sharply — on step 1 one marked
`[25.6–26.4]` (0.8 s) and the other `[14.8–28.9]` (14.1 s), a 17× difference.
